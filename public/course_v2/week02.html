💬 老師的話

這週我们要學 LINE + AI 的超強組合！

LINE 不只是聊天工具，加上 AI 後，它可以幫你：

  • 🌤️ 查天氣（出門前必看）
  • 🌐 翻譯語言（出國旅遊必備）
  • 🍳 查食譜（每天煩惱吃什麼？問 AI！）
  • 📒 記事本（記錄重要事項）

📖 課前準備

🖥️ 課堂內容

第一節：LINE 天氣查詢（19:00-19:45）

🌤️ 為什麼要會查天氣？

出門前看一下天氣，決定要不要帶傘、穿什麼衣服再也不怕淋雨或曬太陽！

方法 1：直接問 LINE

  1. 打開 LINE → 進入 AI 帳號
  2. 傳：「明天天氣怎麼樣？」
  3. 傳：「台北今天天氣」
  4. 傳：「下週天氣」

方法 2：LINE 主頁天氣小工具

  1. 打開 LINE → 點擊「主頁」
  2. 找到「天氣」小工具
  3. 設定你的城市
  4. 每天打開就能看到天氣
💡 課堂練習：
  • 查詢今天天氣
  • 查詢明天天氣
  • 查詢下週天氣趨勢

第二節：AI 翻譯功能（19:45-20:30）

🌐 出國旅遊必學！

去日本、韓國、泰國看不懂菜單？AI 幫你翻譯！

翻譯使用情境

情境怎麼做
看不懂英文說明書拍照傳給 AI → 翻譯成中文
日本菜單拍照 → 翻譯成中文
韓國路標拍照 → 翻譯

常用翻譯指令

指令功能
「翻譯成英文：Hello」翻成英文
「翻譯成日文：你好」翻成日文
「這是什麼意思？（傳圖片）」圖片翻譯

第三節：AI 食譜查詢（20:30-21:15）

🍳 以後不用再問「今天吃什麼」！

AI 幫你想菜單、給你食譜，還會告訴你怎麼做！

超實用指令

  • 「今天晚上吃什麼好？」
  • 「給我一份紅燒肉食譜」
  • 「孕婦可以吃什麼早餐？」
  • 「素食料理食譜」
  • 「糖尿病可以吃什麼？」
💡 AI 食譜的好處：
  • 根據你的需求推薦（人數、口味、食材）
  • 步驟詳細清楚
  • 還會告訴你營養資訊

第四節：LINE 記事本（21:15-22:00）

LINE 記事本可以做什麼？

  • 📓 記錄重要事項
  • 📋 收集好用的資訊
  • ✈️ 整理旅遊計畫
  • 🍳 收藏食譜
  • 💊 記錄用藥時間

建立步驟

  1. 打開 LINE → 進入「主頁」
  2. 點擊「LINE 記事本」
  3. 點擊「建立記事本」
  4. 開始記錄！
