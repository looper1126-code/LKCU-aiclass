💡 本週目標：製作專屬自己的 LINE 貼圖！讓你在 LINE 對話中與眾不同～

🎯 本週學習目標

  • 了解 LINE 貼圖規範
  • 選擇適合的照片素材
  • 用美圖秀秀進行修圖
  • 使用 LINE 貼圖製作工具
  • 完成上架申請

📖 課前準備（非常重要！）

⚠️ 請務必準備以下照片：

🖥️ 課堂內容

第一節：LINE 貼圖規範（19:00-19:45）

  • 數量：最少 8 張，最多 16 張
  • 主圖尺寸：370 x 320 像素
  • 聊天圖示：96 x 96 像素
  • 檔案格式：PNG 或 JPG
  • 檔案大小：每張不超過 500KB

第二節：照片挑選與修圖（19:45-20:30）

  1. 挑選照片：選擇表情清晰、情緒明顯的照片
  2. 裁切：將主體放在中間
  3. 去背：用美圖秀秀 AI 去背（可選）
  4. 調整尺寸：調整為 370 x 320
  5. 加效果：可加上濾鏡或貼紙裝飾

第三節：LINE 貼圖製作工具（20:30-21:15）

  1. 打開 LINE 貼圖製作工具（creator.line.me）
  2. 登入 LINE 帳號
  3. 點擊「建立新貼圖」
  4. 上傳準備好的照片
  5. 為每張貼圖設定標籤（名稱）
  6. 上傳聊天圖示
  7. 設定貼圖資訊（標題、描述、類別）

第四節：提交審核（21:15-22:00）

📋 提交前檢查清單：
  • ✓ 8-16 張貼圖都上傳了
  • ✓ 每張都有設定標籤
  • ✓ 聊天圖示已上傳
  • ✓ 標題和描述已填寫
  • 審核時間：通常 1-2 週
  • 審核標準：原創性、圖片清晰度是否符合規範
  • 通過後：會收到通知，即可上架銷售或免費送朋友

📝 課後複習

🏠 家庭作業

  1. 完成貼圖設計：繼續完成剩下的貼圖照片
  2. 提交審核：完成所有設定並提交
  3. 等待審核：大約 1-2 週後會知道結果
